# Autonomous-RC-Car-ELEC-424-

In our project, we developed an autonomous lane-keeping RC car that uses computer vision and feedback control to navigate a track with blue tape lanes and stop zones. The system runs on a Raspberry Pi and uses OpenCV to detect lane position and compute steering corrections in real time. Our implementation builds on User raja_961's “Autonomous Lane-Keeping Car Using Raspberry Pi and OpenCV” (Instructables) and draws inspiration from several prior ELEC 424 Hackster projects cited in our code.

Here is a link to the project: https://www.hackster.io/team-10/team-10-s-epic-car-7f15dc
